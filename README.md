## 🛠️ Installation & Running / Kurulum ve Çalıştırma

### 1. Clone the Repository / Projeyi İndirin
Open CMD or PowerShell and run the following command:
CMD veya PowerShell'i açın ve aşağıdaki komutu çalıştırın:

pip install -r requirements.txt
python run.py

```bash
git clone [https://github.com/erenberkay1/GozcuGuard-System.git](https://github.com/erenberkay1/GozcuGuard-System.git)
cd GozcuGuard-System
pip install -r requirements.txt
python run.py
